#페이지를 열 때

sequenceDiagram
  participant B as 브라우저
  participant Pg as Pages 정적 파일
  participant Wk as _worker.js
  B->>Pg: index.html, styles.css, sprites.js, main.js, game.js
  Pg-->>B: 200 + _headers 보안 헤더
  B->>B: main.js 부팅 화면, 스프라이트 그리기, 섹션 연출 준비
  B->>Pg: data/quests-detail.json
  Pg-->>B: 프로젝트 상세(실패하면 카드 요약만)
  B->>Wk: assets/pixel-quest.mp4 (Range: bytes=0-)
  Wk->>Pg: env.ASSETS.fetch
  Pg-->>Wk: 200 전체 스트림
  Wk-->>B: 206, 요청한 구간만 잘라 보냄

#Worker의 Range 처리

flowchart TD
  R["요청"] --> M{"GET 또는 HEAD?"}
  M -- "아니오" --> E405["405"]
  M -- "예" --> A["env.ASSETS.fetch로 원본 받기"]
  A --> H{"Range 헤더 있고 200?"}
  H -- "아니오" --> FULL["원본 그대로 + Accept-Ranges·보안 헤더"]
  H -- "예" --> SZ["파일 크기: Content-Length, 없으면 한 번 읽어 세고 ETag별 기억"]
  SZ --> P{"parseRange"}
  P -- "형식 오류·여러 범위" --> FULL
  P -- "범위 밖" --> E416["416 + Content-Range: bytes */크기"]
  P -- "정상" --> S["206 + Content-Range<br/>스트림에서 start~end만 잘라 FixedLengthStream으로"]

#게임 한 판

stateDiagram-v2
  [*] --> title: 직접 플레이하기
  title --> play: 확인 키
  play --> play: P 일시정지 토글
  play --> play: 체력 0이면 체크포인트에서 다시
  play --> clear: 깃발 도착
  clear --> play: 다음 스테이지
  clear --> ending: 마지막 스테이지
  ending --> title: 확인 키
  play --> [*]: Esc 또는 닫기 버튼
  • 장면 이름(title·play·clear·ending)은 state.scene 값이다. 전이는 update()에 있다.
  • 보스 스테이지(2-1·3-1)는 깃발이 처음엔 없고, 보스를 잡으면 생긴다(damageBoss).
  • 체력이 0이 돼도 게임 오버는 없다. 체력 3으로 체크포인트에서 다시 시작한다.

#빌드·실행·배포

# 로컬에서 보기 (fetch 때문에 파일 직접 열기 대신 서버로)
python3 -m http.server 4173      # http://localhost:4173
                                  # 테스트 진입점: http://localhost:4173/?debug

# 배포
./build.sh && npx wrangler pages deploy

# 예전 주소 리다이렉트 Worker 배포 (바꿀 때만)
cd legacy-redirect && npx wrangler deploy
  • build.sh는 index.html styles.css main.js sprites.js game.js _headers data assets를 dist/에 복사하고, worker.js를 dist/_worker.js로, _routes.json(/assets/*.mp4, /assets/*.m4a만 Worker)을 만든다.
  • docs/는 배포하지 않는다.
