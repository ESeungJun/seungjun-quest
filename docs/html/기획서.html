#기획서 · SEUNGJUN QUEST

이미 배포해 쓰고 있는 사이트를 2026-11-05에 코드·git 히스토리·개발 글(dev-post 01-resume-game)에서 거꾸로 정리한 문서다. 코드에 있는 기능을 "요구했던 기능"으로 본다.

#한 줄 소개

안드로이드 개발자 이승준의 이력서·포트폴리오를 레트로 픽셀 게임처럼 꾸민 정적 웹사이트. 사이트 안에서 경력을 스테이지로 옮긴 횡스크롤 게임을 직접 플레이할 수 있다.

  • 주소: https://seungjun-quest.pages.dev

#왜 만들었나

  • 경력과 프로젝트 11개가 노션에 정리돼 있었지만 카드를 늘어놓은 페이지는 흔하고 재미가 없었다.
  • 개발자가 아닌 사람(채용 담당자 등)도 재밌게 볼 수 있어야 했다.
  • 영상은 보는 사람이 가만히 보고만 있어야 한다. 직접 해 보게 만들고 싶었다.
  • 근거: 개발 글 "이력서를 게임으로 만들었다"의 목표 표.

#누가 쓰나

  • 채용 담당자·면접관·동료 개발자: 경력과 프로젝트를 훑어보고 상세를 읽는다.
  • 글(velog·Medium)을 보고 들어온 사람: 게임을 끝까지 해 본다.
  • PC(키보드)와 휴대폰(터치) 둘 다 쓴다.

#핵심 시나리오

  1. 첫 화면에서 CRT TV 안의 소개 영상(1분 7초)을 본다.
  2. 아래로 스크롤하며 STATUS(캐릭터 정보·능력치) → WORLD MAP(경력, 스크롤 따라 캐릭터가 걷는다) → IMPACT(? 블록을 눌러 성과 숫자 열기) → QUEST LOG(프로젝트 11개 저널) → INVENTORY(기술 스택) → CONTINUE(연락처)를 본다.
  3. QUEST LOG에서 프로젝트를 고르면 노션 본문이 "의뢰 내용 → 보상 → 퀘스트 기록" 순서로 나온다.
  4. "직접 플레이하기"를 누르면 게임 창이 열린다. 스테이지 5개를 지나며 표지판에서 그 시기 경력을 읽고, 보스 2마리를 잡고 엔딩까지 간다.
  5. 휴대폰에서는 가상 패드로 한다. 가로로 돌리면 화면이 커진다.

#구현됨

기능 내용
부팅 화면·HUD 시작할 때 부팅 연출. 상단에 점수·코인·현재 WORLD·소리 켜기 버튼
소개 영상 assets/pixel-quest.mp4(1:07)를 CRT TV 모양 안에서 재생
STATUS 캐릭터 정보, 능력치 게이지 6개(연출용이라고 표시)
WORLD MAP 경력 지도. 스크롤 위치에 맞춰 캐릭터가 걷는다
IMPACT ? 블록을 누르면 성과 숫자가 튀어나오고 점수·코인이 오른다
QUEST LOG 프로젝트 11개. 분류 탭, 왼쪽 목록·오른쪽 상세의 RPG 퀘스트 저널. 상세 본문은 data/quests-detail.json
INVENTORY 기술 스택 아이템 칸. 마우스·포커스·클릭으로 설명
CONTINUE 9부터 세는 카운트다운과 연락처(메일·GitHub)
8비트 효과음 Web Audio로 만든 효과음. 기본은 꺼짐
코나미 커맨드 ↑↑↓↓←→←→BA를 누르면 캐릭터가 화면을 달리고 점수 +10000
직접 플레이 게임 320×192 캔버스 플랫포머, 스테이지 5개(WORLD 1-1·1-2·2-1·2-2·3-1), 보스 2마리, 표지판 대사, 일시정지·소리·닫기
게임 조작 키보드(←→ 또는 A·D 이동, Z·↑·W·스페이스 점프, X·J 공격, P 일시정지, M 소리, Esc 닫기), 터치 가상 패드
게임 BGM assets/quest-bgm.m4a. 게임 창이 열려 있고 소리가 켜져 있을 때만 재생
모션 줄이기 prefers-reduced-motion이면 연출을 줄인다
iOS 영상 재생 영상·음악 요청만 Worker가 받아 Range(206) 응답을 만든다
보안 헤더 CSP 등 _headers, Worker 응답에도 nosniff·Referrer-Policy
예전 주소 이동 예전 Workers 주소로 들어오면 새 주소의 같은 경로로 301 이동
테스트 진입점 주소에 ?debug를 붙이면 window.__quest가 생긴다

#나중

  • 기록된 계획 없음.

#범위 밖

  • 서버·DB·로그인: 정적 사이트로 충분하다.
  • 영어판 사이트: 영어 글(Medium)은 있지만 사이트는 한국어만 있다. 만들 계획은 기록 없음.
  • 점수 저장·순위표: 점수는 그 화면에서만 쓴다.

#지원 플랫폼과 배포 채널

  • PC·모바일 최신 브라우저. 모바일 세로·가로 모두 대응한다.
  • 배포: Cloudflare Pages(npx wrangler pages deploy). 저장소의 GitHub Actions 같은 자동 배포는 없다.
  • 공개 저장소다. README에 스크린샷·플레이 영상이 있다.

#완료·성공 기준

개발 글의 목표 표를 그대로 옮긴다.

목표 확인 방법
숫자는 어디서 보든 같게 사이트·게임·프로젝트 상세 데이터에서 같은 숫자를 같은 표현으로 쓰는지 대조
개발자가 아니어도 재밌게 터미널 영상 대신 픽셀 게임 컨셉
보는 것 말고 직접 해 보게 플레이 게임을 넣고 엔딩까지 자동 입력으로 확인
폰에서도 그대로 실기기로 직접 플레이, 발판·아이템이 점프로 닿는지 계산과 실제 점프로 확인
  • 방문자 수·플레이 수 같은 수치는 기록이 없다.
